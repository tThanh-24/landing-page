# Portfolio

Personal site for a CS student. Static, built with Astro 7 and Tailwind CSS 4.

Jobs first, writing second: the home page leads with projects and measured
outcomes, with the résumé and contact form one click away.

## Commands

```sh
npm install       # install dependencies
npm run dev       # http://localhost:4321
npm run check     # type-check .astro and .ts files
npm run build     # build to dist/
npm run preview   # serve the built site
```

## Editing content

All site content lives in `src/data/`. No component changes are needed.

| File | What it holds |
| --- | --- |
| `src/data/site.ts` | Name, tagline, degree, email, socials, résumé file name, hero phrases |
| `src/data/projects.ts` | Project list — the most important file on the site |
| `src/data/experience.ts` | Roles, internships, research, TAships |
| `src/data/writing.ts` | Blog/newsletter entries. Empty hides the section |
| `src/data/skills.ts` | Skill groups rendered on `/resume` |

### First thing to do

Set `site.url` in `src/data/site.ts` to your real domain. It is used for
canonical URLs, the sitemap, and Open Graph tags. Then replace the placeholder
name, tagline, email, and social handles in the same file.

### Adding a project

Append an entry to the `projects` array in `src/data/projects.ts`:

```ts
{
  title: "Query Planner",
  blurb: "A cost-based optimizer for distributed joins. Two sentences at most.",
  year: "2025",
  tags: ["rust", "postgres"],
  links: { repo: "https://github.com/you/query-planner" },
  featured: true,
  metrics: [
    { value: "3.2x", label: "faster than baseline" },
    { value: "18k", label: "queries in the benchmark" },
  ],
}
```

`featured: true` puts the project on the home page (the first three appear).
A screenshot is optional — drop the file in `public/projects/` and add
`image: "/projects/your-file.png"`.

**Add a `metrics` entry to every project you can.** A number tells a reviewer
you measured your work, which is the cheapest credibility on a portfolio.

### Adding the résumé PDF

Drop your file at `public/resume.pdf`. The name is configurable via
`site.resumeFile` in `src/data/site.ts`. Until the file exists, the download
button renders as a disabled "PDF coming soon" state rather than a 404, and
`/resume` explains the step. No rebuild logic to change.

### Adding a writing entry

```ts
{ title: "Why I stopped using Redis", date: "2025-06-14", url: "https://...", blurb: "One line.", kind: "Note" }
```

The Writing section on the home page appears automatically once the array is
non-empty.

## Structure

```
public/            static assets: favicon, og.svg, robots.txt, resume.pdf
src/
  components/      header, footer, sections, cards, theme toggle, reveal
  data/            all editable content
  layouts/         BaseLayout: meta tags, theme script, header/footer shell
  pages/           index, work, resume, 404
  styles/          global.css: Tailwind import, theme tokens, shared classes
```

## Theming

Colors are CSS custom properties in `src/styles/global.css` under `@layer
base`, defined twice: once for light, once for `.dark`. Change `--bg`, `--fg`,
and `--color-accent` there to restyle the whole site.

The toggle cycles system → light → dark and stores the choice in
`localStorage` under `theme`. An inline script in `<head>` applies it before
first paint, so there is no flash of the wrong theme. It follows the OS
setting when the user has not chosen explicitly.

## Motion

`Reveal.astro` fades content up on scroll via IntersectionObserver. It is
skipped for `prefers-reduced-motion`, and a `.no-js` fallback keeps content
visible when JavaScript is unavailable.

## Deploying

The output in `dist/` is fully static, so any host works. Nothing is
configured yet. When you pick one:

- **Netlify** — build `npm run build`, publish `dist/`
- **Vercel** — framework preset Astro, output `dist/`
- **GitHub Pages** — set `site.url` to the `user.github.io` URL, add the
  `base` option in `astro.config.mjs` if using a project subpath

## SEO

- Per-page title, description, and canonical URL
- Open Graph and Twitter card tags pointing at `public/og.svg` (1200×630).
  Replace the placeholder text in that file with your name and tagline
- Sitemap generated by `@astrojs/sitemap`; `robots.txt` references it
- One `<h1>` per page, skip-to-content link, labeled nav landmarks
